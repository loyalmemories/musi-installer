# Design references

The interface follows established desktop utility layouts: compact navigation, conventional labels and fields, a restrained accent color, aligned progress rows, and standard dialogs.

References reviewed:

- Apple Devices for Windows: https://support.apple.com/en-us/120402
- GitHub Desktop interface: https://github.com/desktop/desktop
- Fluent layout: https://fluent2.microsoft.design/layout
- Fluent progress guidance: https://fluent2.microsoft.design/components/web/react/core/progressbar/usage

Progress bars switch from activity indicators to measured percentages when the backend supplies enough information. Transfer estimates are labeled approximate. Completed-step count is separate from transfer percentages.

No assets, logos or implementation code from these interface examples are included.
